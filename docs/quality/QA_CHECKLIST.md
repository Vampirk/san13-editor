## 2. 세이브/로드 및 시간 진행 안전성 점검 (인간 테스터 수행용)

> **주의:** AI 에이전트는 외부 게임 바이너리의 화면 조작 및 마우스 클릭을 직접 수행할 수 없으므로,  
> 사용자가 게임 내에서 직접 아래 5개 단계를 순서대로 수행하여 안전성을 확인해야 합니다.

### [테스트 1] 기본 수치 실시간 수정 및 인게임 즉시 반영 검증
1. 삼국지 13 PK 실행 후 시나리오 진입 (예: 190년 반동탁 연합).
2. 에디터 실행 후 임의 무장 선택 (예: 조운 ID 380).
3. 조운의 무력을 `96`에서 `100`으로 수정 후 [메모리 커밋(핫싱크)] 클릭.
4. 게임 화면에서 이미 열려 있는 창이 있다면 닫고, 조운의 무장 정보창을 다시 오픈.
5. **확인 사항:** 무력이 `100`으로 즉시 변경되어 표시되는가?
   - [ ] 성공 / [ ] 실패

### [테스트 2] 인게임 세이브 데이터 저장 및 재로드 영구 보존 검증
1. [테스트 1] 상태에서 게임 내 메뉴 → [저장하기] 선택 (기존 세이브 보호를 위해 **새 슬롯**에 저장 권장).
2. 저장이 완료되면 게임 메인 메뉴(타이틀 화면)로 완전히 복귀.
3. [불러오기]를 통해 방금 저장한 세이브 데이터 로드.
4. 조운의 무장 정보창을 열어 수치 확인.
5. **확인 사항:** 에디터로 변경했던 `100` 수치가 롤백되지 않고 그대로 유지되는가?
   - [ ] 유지됨 (성공) / [ ] 덮어쓰여짐 (실패)

### [테스트 3] 월말 일자 롤오버 (30일 진행) 및 엔진 재계산 안정성 검증
1. 게임 속도를 보통/빠름으로 설정하고 날짜를 1개월 이상 진행 (예: 1월 1일 -> 2월 1일 -> 3월 1일).
2. 월말 일괄 정산(자원 증가, 충성도 변동, 계절 변화) 트리거 발생.
3. **확인 사항:**
   - 월말 정산 시 게임이 강제 종료(크래시/CTD)되지 않고 정상 진행되는가?
     - [ ] 크래시 없음 (성공) / [ ] 크래시 발생 (실패)
   - 에디터로 수정한 수치가 게임 엔진 내부 주기적 재계산 루틴에 의해 강제 초기화되지 않는가?
     - [ ] 수치 유지됨 / [ ] 엔진에 의해 초기화됨

### [테스트 4] 한계 돌파(LimitBreak 255) 수치 세이브/로드 안정성 검증
1. 임의 무장에게 한계 돌파 모드로 통솔/무력을 `200`으로 설정.
2. 인게임 무장 정보창 확인 (게임 UI 폰트 깨짐이나 오버플로 없이 표시되는지 확인).
3. 세이브 저장 후 타이틀 복귀 -> 재로드.
4. **확인 사항:**
   - 게임 엔진 세이브 파일 포맷이 8비트 부호 없는 정수(0~255)를 온전히 지원하여 `200`이 보존되는가?
     - [ ] 200 유지됨 / [ ] 100으로 자동 클램핑됨 / [ ] 데이터 손상
   - 전투(일기토 또는 야전) 진입 시 게임 크래시가 발생하는가?
     - [ ] 정상 전투 수행 / [ ] 전투 진입 시 크래시

### [테스트 5] 전법/특기/외모 CG 변경 후 저장 안정성 검증
1. 조조의 전법을 "군신"(ID 2), 얼굴 CG를 관우(ID 117)로 변경.
2. 세이브 저장 후 게임 완전 종료 (`wineserver -k` 또는 Steam 종료).
3. 게임 재실행 후 해당 세이브 로드.
4. **확인 사항:**
   - 전법 "군신"과 얼굴 CG가 세이브 파일에 정상 기록되어 재실행 후에도 온전히 복원되는가?
     - [ ] 완벽 복원됨 / [ ] 기본값 복구됨
