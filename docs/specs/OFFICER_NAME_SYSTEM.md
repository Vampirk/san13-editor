# 삼국지 13 PK 전체 무장 이름 시스템 및 공식 텍스트 역분석 명세

> **문서 상태:** 확정됨 (Verified SSOT)  
> **최종 갱신일:** 2026-10-04  
> **대상 데이터:** 삼국지 13 with 파워업키트 (San13PK Korean Version)  
> **원본 아카이브:** `DATA1.S13` (Entry 1655 / `unpacked_pk/data/pk_1655.tbl`)

---

## 1. 개요 및 목적

본 문서는 삼국지 13 PK의 전체 무장 슬롯(ID 0 ~ 1450)과 게임 공식 한글 데이터 파일(`pk_1655.tbl`) 간의 역분석 결과를 수록한 단일 진실 공급원(SSOT) 기술 명세서입니다.

게임 내에서 일부 추가 무장이 실명 대신 임의의 번호(예: `#1242`)로 노출되는 현상을 완벽히 해결하고, 오리지널 역사 무장 700인뿐만 아니라 **PK 공식 추가 사실무장 100인**, **고대무장**, **이벤트 NPC**, **등록 신무장(`editdata_pk.s13`)**에 이르기까지 게임 엔진이 무장 이름을 참조하는 정확한 데이터 구조와 인덱싱 규칙을 영구 보존합니다.

## 2. 게임 원본 바이너리 컨테이너 구조 (`pk_1655.tbl`)

삼국지 13 PK의 모든 텍스트 메시지 및 고유 명사(부락 지명, 명품명, 무장 성명/열전 등)는 `DATA1.S13`의 **Entry 1655**(`pk_1655.tbl`, 708,848 바이트)에 수록되어 있습니다.

### 2.1. 파일 계층 구조
1. **아우터 컨테이너 (Table Header, 0x00 ~ 0x27)**:
   - `0x00`: 포맷 버전 (`0x00000001`)
   - `0x08`: 전체 페이로드 크기 (`0x000AD0E4` = 708,836B)
   - `0x0C`: 섹션 수 (`3`개 섹션)
2. **섹션 1 (`XL13` 서브 컨테이너, 0x28 ~ 0x9FFFF)**:
   - `0x28`: 매직 넘버 (`b"XL\x13\x00"`)
   - `0x34`: 헤더 길이 (`0x00000014` = 20바이트)
   - `0x3C`: 32비트 포인터 배열 시작 지점 (총 26,819개 포인터)
   - **문자열 인코딩**: 한국어 `CP949` (EUC-KR)

### 2.2. 포인터 역참조 및 문자열 해석 공식
포인터 테이블의 각 원소 `pointers[idx]`는 `0x3C`를 기준으로 하는 상대 오프셋입니다.
$$\text{FileOffset}(idx) = \text{0x3C} + \text{pointers}[idx]$$

## 3. 무장 이름 블록 인덱싱 수학 공식

`XL13` 포인터 테이블 내에서 무장의 성(姓), 명(名), 자(字)는 각각 1,450개의 슬롯 크기를 갖는 독립 블록으로 균일하게 배치되어 있습니다.

| 속성 | 베이스 인덱스 ($\text{Base}$) | 조회 공식 | 설명 |
| :--- | :---: | :--- | :--- |
| **성(姓, Surname)** | **`6535`** | `GetString(6535 + OfficerID)` | 성씨 (예: "유", "조", "제갈", "황보") |
| **명(名, Given Name)** | **`7985`** | `GetString(7985 + OfficerID)` | 이름 (예: "의", "조", "량", "개") |
| **자(字, Courtesy Name)** | **`9435`** | `GetString(9435 + OfficerID)` | 자 (예: "공명", "맹덕", "운장", "본초") |

$$\text{FullName}(ID) = \text{GetString}(6535 + ID) + \text{GetString}(7985 + ID)$$

## 6. 등록 신무장(`editdata_pk.s13`) 아키텍처 연동 규격

플레이어가 인게임 "등록무장 작성" 기능으로 생성한 신무장은 게임 원본 아카이브가 아닌 사용자 로컬 PC에 바이너리 파일로 저장됩니다.

- **저장 위치**: `Documents/KoeiTecmo/San13/KR_SAVEDATA/editdata_pk.s13`
- **레코드 마커**: `b"EntryBushou"`
- **오프셋 구조**:
  - `Marker + 0x20`: 성(Surname, 최대 6바이트 CP949)
  - `Marker + 0x25` (또는 `+0x26`): 명(Given Name, 최대 6바이트 CP949)
- **에디터 구현부**: [`src/game/OfficerNameTable.cpp`](../src/game/OfficerNameTable.cpp#L829-L875) 내의 `LoadCustomOfficerNames()` 함수가 이 파일을 직접 파싱하여 700~849번 슬롯에 실시간 동적 주입합니다.
